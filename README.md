# Vibora — Phase 1 prototype

A self-contained, local prototype for the compliant **social watch-room** MVP defined in the WatchParty product work.

## Run it

Open `index.html` in any modern browser. No build process, account, API key, or streaming credentials are required.

## Included flow

1. Profile onboarding and entertainment-interest selection
2. Private-room creation or invite-code joining
3. Group-aware recommendation choices and voting
4. Simulated synchronized playback controls
5. Room members and real-time-style local chat

This intentionally does **not** embed or proxy OTT content. Production playback should use provider-authorized players (starting with YouTube’s IFrame Player API) while Vibora remains the social, recommendation, and room-coordination layer.
